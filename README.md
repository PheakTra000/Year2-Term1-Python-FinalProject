With this project, we want to install multiple dependencies and a certain tool in order for it to work. Make sure that your device have python installed.

Dependencies: 

- Cryptography

pip install Cryptography

- Pynput

pip install Pynput

Tool: 

- Pyinstaller

pip install pyinstaller

# Run the server.py 

Firstly, you need to run the server.py script through cmd where the file located or terminal. You can also set the port to your desire. After it, the server will run and waiting for connection.
You can interrupt the server to stop running by pressing Ctrl+C.
